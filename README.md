### 🧠 My Learning & Documentation Methodology

If you look through these notes, you will notice that every single mathematical step, matrix operation, and proof matches the video lectures word-for-word and step-by-step. However, **this alignment does not mean there is a lack of effort—on the contrary, it represents a rigorous, hands-on learning workflow:**

1. **Step-by-Step Manual Note-Taking:** While watching the video lectures, I write down every single step, equation, and concept manually in my physical notebook, ensuring not a single detail from the lecture is missed.
2. **First-Principles Comprehension:** I never treat a note as complete until I fully understand the underlying logic and intuition behind it. 
3. **AI-Assisted Workflow & Synthesis:** Since manually typing complex mathematical formatting, matrices, and code from scratch is inefficient, I leverage AI. After finishing a video lecture and completing my handwritten notes, I provide the video link along with snapshots of my notes to Google Gemini, using custom prompts to synthesize and format the materials into professional Jupyter Notebooks.
4. **Interactive Python Visualizations:** To bridge abstract algebra with real-world visualization, I write executable Python code (using NumPy and Plotly) to embed interactive 2D and 3D graphs directly into the notebooks.
